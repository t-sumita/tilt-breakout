# TILT BREAKOUT

回転リング×固定障害物×ブロック崩しを組み合わせたブラウザゲームです。

## はじまり

富士急ハイランドの「絶望要塞」というアトラクションで遊んだとき、その中に組み込まれていた変わったルールのブロック崩しがとても面白く、強く印象に残りました。固定された障害物や回転するジャマーを避けながら、ただ跳ね返すだけでは終わらないブロック崩しという発想へのリスペクトとして、本ゲームを個人で作りました。

▶ **[https://tilt-breakout.subutomo.dev/](https://tilt-breakout.subutomo.dev/)**

## 遊び方

- 全3ステージを順番にクリアしていくブラウザゲームです。タイトル画面でタップ(または Space/Enter)するとスタートします。
- パドルにボールが乗っている状態でもう一度タップすると発射されます。
- 制限時間内にステージのブロック(ターゲット)をすべて壊すとステージクリアです。ボールを落とすと残機が1つ減ります。残機がなくなる、または制限時間が0になるとゲームオーバーです。
- ステージ1→2→3を**通しで**クリアすると、オールクリア演出が発生します(Config画面のステージ選択で途中からジャンプした場合はオールクリア判定の対象外です)。

### 操作方法

| 入力 | 操作内容 |
|------|----------|
| 1本指スワイプ(タッチ)/ マウスドラッグ | パドルの2D移動(左右+上下) |
| 2本指タッチ | パドルの傾き調整(左右の指の高さの差で傾く) |
| 矢印キー | パドルの2D移動 |
| Q / E(または , / .) | パドルの傾き調整 |
| Space / Enter | 発射・各種決定操作 |

> 本ゲームはスマートフォンでのタッチ操作(スワイプでの移動、2本指での傾き調整)の方が、PCでのマウス/キーボード操作より快適に遊べます。

## ステージ構成

1. **STAGE 1 — 王道配置**
   王道のブロック崩し配置をベースに、上寄せでテンポよく崩せるレイアウトです。1列目と3列目の一部は3ヒットで壊れるハードブロックになっており、3列目には破壊不能ジャマーも左右対称に混在します。
2. **STAGE 2 — 固定障害物面**
   中央に凹型のブラケット構造(唯一の横穴を通してボールを送り込む必要がある)と、その奥の大きな正方形ブロック、回転する十字ジャマー、回転する三角ジャマー、横に往復する棒ジャマーが組み合わさった、狙いを絞って通す必要があるステージです。下段には通常ブロックとジャマーが交互に混在する2段の横列もあります。
3. **STAGE 3 — 回転リング面**
   中心のコアブロックだけが破壊対象で、その周囲を3枚の回転リングが囲んでいます。各リングには常にどこかに隙間(開口部)があり、リングの回転に合わせてタイミングよく隙間を通す必要があります。

すべてのステージは、狙えば必ず抜けられる「本物の隙間」が理論上100%クリア可能な形で確保されるよう設計されています。

## 玉の物理挙動

- ボールは単純な等速反射ではなく、**重力+空気抵抗(減衰)モデル**で常に速度が変化します。放物線を描きながら落下し、壁・ブロック・ジャマー・パドルに当たるたびに反発します。
- 反発の直後には最低速度が保証されており、画面のどの位置で跳ね返っても重力に負けず上部まで届く勢いを維持します。
- パドルを素早く動かして当てると通常の反発、逆にゆっくり(または止まった状態)で当てると大きく減速する「受け」動作になります。
- 受けによって速度が一定のしきい値を下回ると、ボールはパドルに**キャッチ**されて追従するようになります。キャッチ中に発射操作(タップ/Space/Enter)を行うと、パドルの傾きに応じた角度で**再発射**されます。発射・再発射は同じ操作系に統一されています。

## Config画面

HUD右上の⚙ボタンから、以下の項目を実行時にスライダー/セレクトボックスで調整できます(開いている間はゲームが一時停止します)。

- パドル移動速度
- 重力
- 空気抵抗
- 制限時間
- ボール数(残機)
- キャッチ速度しきい値(この速度未満でパドルに触れるとキャッチされる)
- ステージ選択(直接ジャンプ。オールクリア判定の対象外になります)

各項目には現在値と一緒に既定値が常に表示され、「規定値に戻す」ボタンで全項目を一括リセットできます。

## オールクリア演出・ハイスコア

- ステージ1→2→3を通しでクリアすると、花火とともに「CONGRATULATIONS!」が表示されるオールクリア演出が発生します。
- スコアは HUD に常時表示され、ハイスコアはブラウザの localStorage に保存されて次回以降も表示されます。

## デモプレイ(アトラクトモード)

タイトル画面のまま一定時間(60秒)操作がないと、1〜3のいずれかのステージをランダムに選んで自動プレイのデモが始まります。デモ中のプレイ内容はスコア・ハイスコアなど実際の記録には一切反映されず、タップ・クリック・キー入力などなんらかの操作を行うと即座にデモが終了し、通常のタイトル画面に戻ります。
